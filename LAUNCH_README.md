# Preesho Launch Package

This is the most complete source package that can be prepared without access to private third-party accounts.

Included:
- Mobile shopping UI
- Product/category/search/cart/address/login/profile flows
- Backend service abstraction
- Local development backend
- Admin/API specification
- Store listing draft
- Release checklist
- Privacy-policy template
- Terms template

To make it actually live, the remaining external steps are account/credential actions:
1. Create/configure Firebase or Supabase.
2. Connect authentication/database/storage.
3. Load real products and categories.
4. Set the final package/application ID and app branding.
5. Create Android signing credentials.
6. Create/configure Google Play Console.
7. Build a signed AAB.
8. Complete Play Store listing, privacy policy and required declarations.
9. Upload AAB and submit for review.
10. Connect payment gateway when ready.

Never send private passwords, service-account keys, signing keys or payment secret keys in chat.
